Prototipo interactivo - App de metas en pareja

Archivos:
- index.html
- styles.css
- app.js

Cómo usar:
1. Abre `index.html` en el navegador (doble clic o `open`).
2. Navega con la barra superior: Dashboard, Mi Día, Recompensas, Chat, Reporte, Settings.
3. En "Mi Día" puedes marcar tareas completadas y ver animación de confeti.

Notas:
- Es un prototipo ligero para validar flujo y UX; no tiene backend.
- Si quieres, puedo convertirlo a un prototipo Flutter o exportar a Figma.
